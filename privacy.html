Privacy Policy

Last updated: 14 November 2026

Personal Gmail Reader is a private script that its owner runs on their own computer to read Gmail accounts belonging to the owner and members of the owner's household.

What it accesses

For each account, only after that account's holder has signed in and given consent on Google's consent screen, it uses the Gmail API with read-only access (https://www.googleapis.com/auth/gmail.readonly) to search and read messages in that mailbox. It cannot send, modify or delete email.

How data is used and stored

  • Messages are read only when the owner runs the script, and only to answer what was asked, such as matching a receipt to a household or company expense.
  • Each account's OAuth refresh token is stored in the macOS Keychain on the owner's computer.
  • No email content, metadata or account information is sent to, stored on, or shared with any server or third party, other than Google's own APIs.
  • No data is used for advertising, sold, or used to train models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Each account holder can revoke access to their account at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue in this site's GitHub repository.
